# AIOT Final Project - 數位人 AI 旅遊規劃器

一個結合數位人互動、語音識別和 TTS 語音合成的智能旅遊助理應用程式。

## 專案簡介

本專案是一個創新的 AI 旅遊規劃應用程式,透過虛擬數位人提供沉浸式的旅遊諮詢體驗。使用者可以透過語音與數位人自然對話,獲得個性化的旅遊建議和即時資訊。

## 核心功能

### 🎭 數位人互動體驗
數位人擔任旅遊顧問的角色,提供視覺化的互動體驗：
- 逼真的數位人渲染與表情動畫
- 說話時的嘴形同步技術
- 自然流暢的對話互動
- 來源：[https://github.com/duixcom/Duix-Mobile?tab=readme-ov-file](https://github.com/duixcom/Duix-Mobile?tab=readme-ov-file)

### 🎤 即時語音識別
支援使用者透過語音與系統溝通：
- 即時將語音轉換為文字
- 動態顯示識別結果字幕
- 支援中文語音輸入

### 🔊 智能語音合成
將 AI 回應轉換為自然的語音輸出：
- 支援多種音訊格式（PCM / WAV）
- 使用 Microsoft Edge TTS 引擎
- 提供流暢的中文語音合成

### 🏖️ 旅遊規劃助理
整合各項功能,提供完整的旅遊規劃服務：
- 旅遊景點推薦
- 行程安排建議
- 即時旅遊資訊查詢

## 技術架構

### 開發框架
- **Flutter 3.10.3**：跨平台應用開發框架
- **Riverpod 3.0.3**：現代化的狀態管理解決方案

### 核心技術整合
- **DUIX SDK**：矽基智能的數位人渲染引擎
- **speech_to_text**：Google 語音識別服務
- **Edge TTS API**：Microsoft 的語音合成服務
- **Dio**：高效的 HTTP 網路請求框架

### 專案架構設計
採用分層架構設計,確保代碼的可維護性和擴展性：
- **UI 層**：使用 Flutter Widget 構建使用者界面
- **狀態管理層**：透過 Riverpod Providers 管理應用狀態
- **業務邏輯層**：Repository 模式封裝業務邏輯
- **服務層**：與外部服務（DUIX、TTS）的整合
- **網路層**：統一的 API 請求處理與錯誤管理

   - 啟動 Flutter 應用程式

## 應用場景

### 旅遊諮詢
使用者可以詢問任何旅遊相關問題,數位人將提供專業建議：
- 「台北有什麼好玩的景點？」
- 「推薦三天兩夜的台南行程」
- 「墾丁適合什麼季節去？」

### 行程規劃
根據使用者的偏好和需求,智能安排旅遊行程：
- 景點推薦與順序安排
- 交通路線規劃
- 住宿與美食建議

### 即時互動
透過語音對話,提供自然流暢的使用體驗：
- 免打字,用說的就能查詢資訊
- 數位人即時語音回應
- 視覺化的互動體驗

## 技術亮點

### 效能優化
- 採用 Riverpod 自動狀態管理,減少不必要的 UI 重建
- API 服務使用單例模式,避免重複實例化
- Binary 音訊數據直接處理,提升傳輸效率
- 統一的錯誤處理機制,提升應用穩定性

### 用戶體驗
- 完善的中文錯誤提示
- 智能的網路狀態檢測
- 流暢的語音識別與合成
- 自然的數位人互動效果

### 開發體驗
- 清晰的分層架構
- 完整的類型安全檢查
- 自動化的程式碼生成
- 統一的 API 請求處理

## 已知限制

- 需要網路連線才能使用 TTS 和語音識別功能
- 數位人渲染需要較高的設備效能
- 目前僅支援中文語音識別和合成
